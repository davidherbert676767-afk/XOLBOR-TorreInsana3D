# XOLBOR - Torre Insana 3D

Projeto Godot 4 para teste separado da Torre Insana 3D.

## Gerar APK pelo GitHub
1. Envie esta pasta/projeto para um repositório.
2. Abra Actions.
3. Execute `Build Torre Insana 3D APK`.
4. Baixe o artifact `XOLBOR-TorreInsana-3D-APK`.

Este APK é um teste separado. Depois que o jogo for validado no celular, os recursos podem ser integrados ao aplicativo XOLBOR principal.
